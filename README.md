# Air Fryer Market Demand Analysis

## Overview
1-2 paragraphs explaining the question and dataset.

## Questions
- How has the air fryer market changed from 2019–2023?
- What product characteristics are associated with demand?
- How sensitive is demand to price?
- What can the demand model tell us about costs and markups?

## Methods
- Exploratory data analysis
- Logit-style demand estimation
- Linear regression
- Demand elasticity / price coefficient
- Implied marginal costs
- Markup and profit analysis

## Key Findings
- Price coefficient: -0.0377
- R²: 0.7635
- Average implied unit cost: $93.10
- Average markup: $29.70
